# Shared standards

The canonical policy text is kept with the original, installable skill rather
than duplicated across many policy files:

| Standard | Source of truth |
| --- | --- |
| Readability, simplicity and architecture | [fleet-engineering](../skills/fleet-engineering/SKILL.md) |
| Focused retrieval and context cost | [fleet-context](../skills/fleet-context/SKILL.md) |
| Experiments, baselines, data and compute | [fleet-research](../skills/fleet-research/SKILL.md) |
| Evidence, citations and claims | [fleet-academic](../skills/fleet-academic/SKILL.md) |
| Ownership and acceptance criteria | [fleet-delivery](../skills/fleet-delivery/SKILL.md) |

These policies guide agent behavior. File integrity and version checks are
enforced by the CLI; engineering and scientific quality still require review
and appropriate project checks. Project-specific rules belong in the project.
